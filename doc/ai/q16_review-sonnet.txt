● Good — the R2 report has the exact line you need: "Number of sequence pairs
  removed because at least one read was shorter than the length cutoff (X%)".
  Here's a simple command:

  grep -A1 "pairs removed because"
  results/trimgalore/*_R2.fastq.gz_trimming_report.txt

  Explanation:
  - grep searches text files for a pattern.
  - -A1 tells grep to also print the 1 line after each match (because the
    percentage is on the matching line, but you may want to confirm with the
    count on the next line — actually here the percentage is already in the
    matching line itself, so -A1 just shows you the number too).
  - "pairs removed because" is the text we're searching for — it only appears
    once per report, right where the removed-pairs percentage is printed.
  - results/trimgalore/*_R2.fastq.gz_trimming_report.txt uses the * wildcard to
    match this pattern in every sample's R2 report (the pairs-removed stat only
    appears in the R2 file, since that's where Trim Galore does the paired-end
    validation step).

  Sample output will look like:
  results/trimgalore/S63_R2.fastq.gz_trimming_report.txt:Number of sequence
  pairs removed because at least one read was shorter than the length cutoff
  (7.40%):
  results/trimgalore/S63_R2.fastq.gz_trimming_report.txt-
           37,016

  If you just want the filename and percentage on one line (cleaner), use:

  grep "pairs removed because"
  results/trimgalore/*_R2.fastq.gz_trimming_report.txt

  This drops -A1, so you only get the line with the percentage, prefixed by the
  filename — no count line underneath.
